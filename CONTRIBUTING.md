# Contributing

Thank you for considering a contribution to the HEP–ML Living Guide.

For full contribution guidance — what makes a good section, the editorial
criteria, the structure each section should follow — see the
**[Contribute](https://iml-wg.github.io/HEPML-LivingGuide/contribute/)** page on
the site.

## Quick reference

There are three kinds of contribution, in increasing order of effort:

1. **Suggest a paper or flag an error** — open an
   [issue](https://github.com/iml-wg/HEPML-LivingGuide/issues) or a pull request
   that edits the relevant section.
2. **Update an existing section** — open a pull request and update the
   "Last updated" stamp.
3. **Write a new section** — please [open an issue first](https://github.com/iml-wg/HEPML-LivingGuide/issues/new)
   to announce your intent, then follow the section template (see
   `docs/applications/anomaly-detection.md` for a worked example).
