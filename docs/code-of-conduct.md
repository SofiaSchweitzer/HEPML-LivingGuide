# Code of conduct

The HEP–ML Living Guide is a community resource. All contributors, maintainers,
and participants are expected to follow the
[Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive in discussions and reviews.
- Disagreements on inclusion criteria, scope, or wording are normal — handle
  them on technical grounds.
- Harassment, personal attacks, and discriminatory behavior are not tolerated.

## Reporting

If you experience or witness behavior that violates the code of conduct, please
contact the maintainers privately. Contact details are listed on the
[About](about.md) page.

The maintainers will respond promptly and treat all reports confidentially.
