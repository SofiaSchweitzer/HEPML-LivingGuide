# By HEP application

These sections are organized by the physics problem being solved, within the
[scope](../about.md) of the Guide: particle physics, not nuclear or heavy-ion
physics, astroparticle physics, cosmology, or accelerator applications. If you have a
methodology in mind rather than an application, [browse by ML method](../methods/index.md)
instead.

## Sections

- [Triggering](triggering.md) — real-time event selection, hardware-aware ML, low-latency inference
- [Reconstruction](reconstruction.md) — tracking, calorimetry, particle flow, jet tagging
- [Simulation & fast emulation](simulation.md) — the whole simulation chain: amplitudes, phase-space sampling, event generation, and detector response
- [Unfolding & simulation-based inference](unfolding-inference.md) — detector unfolding, parameter estimation, limit setting from simulators without a tractable likelihood
- [Anomaly detection](anomaly-detection.md) — model-agnostic searches for new physics
- [Phenomenology](phenomenology.md) — parton distributions, global fits, BSM scans, reinterpretation, symbolic methods
- [Formal theory](formal-theory.md) — ML for formal theoretical problems, including string theory and lattice gauge theory
- [Lattice QCD](lattice.md) — ML for lattice configurations, observables, and flow-based sampling

!!! note "Some sections may be empty for now"
    The Guide is community-written. A section appears here once a contributor has
    written it. If a section you care about is missing or only a stub, please consider
    [contributing](../contribute.md).
